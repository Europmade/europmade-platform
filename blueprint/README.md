# Blueprint

Dit is het **einddocument** van de business- en productstrategie van EuropMade — de vaste, externe bron van waarheid waarop alle documentatie in `docs/` is gebaseerd. Deze map bevat uitsluitend het brondocument zelf, in twee formaten, en wordt niet vermengd met technische of UX-documentatie.

## Inhoud

- `EuropMade_Blueprint_V2_1.docx` — bewerkbaar bronbestand.
- `EuropMade_Blueprint_V2_1.pdf` — gepubliceerde, niet-bewerkbare versie voor distributie/archief.

## Belangrijk

- Dit document wordt **niet** vanuit de repository bewerkt. Wijzigingen aan de Blueprint zelf verlopen buiten deze repository om, en een nieuwe versie wordt hier pas geplaatst zodra deze extern is vastgesteld.
- Alle documentatie onder `docs/` verwijst naar hoofdstukken van dit document (bijv. "H8.5") in plaats van de inhoud te dupliceren. Zie [`docs/00-context/blueprint-reference.md`](../docs/00-context/blueprint-reference.md) voor het hoofdstukoverzicht en de koppeling naar de rest van de documentatie.
- Wijzigt de Blueprint-versie (bijv. naar v2.2), dan wordt dat vastgelegd als nieuwe ADR in [`docs/04-decisions/`](../docs/04-decisions/README.md), omdat een Blueprint-wijziging per definitie downstream-documentatie kan raken.
