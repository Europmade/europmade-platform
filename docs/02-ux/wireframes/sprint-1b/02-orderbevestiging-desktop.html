BTW-regel (vereenvoudigd): toont uitsluitend label + bedrag + info-icoon (ⓘ) — geen losse toelichtende tekst en geen standaard zichtbare uitsplitsing meer. Het info-icoon (hergebruikt patroon, zelfde als elders in de Buy Box/EU-eigendom) toont bij hover/klik een compacte tooltip met de berekeningswijze, het land en het toegepaste tarief. **Bij meerdere tarieven binnen dezelfde bestelling** bevat diezelfde tooltip aanvullend een uitsplitsing per tarief (21%/9%/0%) — uitsluitend zichtbaar via het icoon, nooit standaard op de pagina.
