# 00 — Context

Deze map bevat geen nieuwe inhoud, maar legt vast **waar alle andere documentatie op is gebaseerd** en welke terminologie consistent wordt gebruikt.

## Inhoud

- [`blueprint-reference.md`](./blueprint-reference.md) — herkomst en hoofdstukoverzicht van de EuropMade Blueprint (v2.1) en het financieel model (v1.0), die als vaste, externe basis dienen voor alle documentatie in dit repository.
- [`glossary.md`](./glossary.md) — begrippenlijst van EuropMade-specifieke termen (Product Cloud, Commerce Cloud, Buy Box, Verified™, Retailer Created, etc.), zodat terminologie in alle documenten consistent blijft.

## Belangrijk

De Blueprint en het financieel model zelf zijn **brondocumenten van de business- en financiële strategie**, geen technische of UX-documentatie. Ze worden hier niet gedupliceerd, maar staan als los einddocument in de repository-brede map [`/blueprint/`](../../blueprint/README.md) (docx + pdf), en worden vanuit alle documentatie in `docs/` met hoofdstukverwijzingen (bijv. "H8.5") aangehaald.
